# E-Commerce Customer Churn Analysis – SQL

## 📌 Overview

A SQL-based **E-Commerce Customer Churn Analysis** project focused on cleaning customer data and extracting business insights using MySQL.

## 🛠️ Skills & Concepts

* MySQL
* Data Cleaning & Transformation
* Missing Value Imputation
* Outlier Handling
* Data Standardization
* Aggregate Functions & Subqueries
* CASE Statements
* Joins
* User-Defined Functions
* Customer Churn Analysis

## 📊 Analysis Performed

The project analyzes:

* Churned vs. active customers
* Customer tenure and satisfaction
* Complaints and churn behavior
* Preferred payment methods
* Order categories and purchasing behavior
* Warehouse-to-home distance
* Coupon usage and cashback
* Customer returns and refunds

The SQL script also creates derived fields such as **ChurnStatus** and **ComplaintReceived** for easier analysis.

## 💡 Key Learning

This project demonstrates how SQL can transform raw e-commerce customer data into **clean, structured, and analysis-ready data**, while using queries to identify patterns related to customer churn and engagement.
