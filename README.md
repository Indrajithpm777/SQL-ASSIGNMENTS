# SQL-ASSIGNMENTS

## 📌 Overview

This is a beginner-level **SQL mini project** created to practice fundamental SQL concepts using an employee database.

The project contains employee details such as department, location, designation, age, hire date, and salary. SQL queries are used to retrieve, filter, sort, group, and analyze the data.

## 🗂️ Dataset

The database includes:

* Employee information
* Department details
* Location details
* Designations
* Salary information
* Hiring dates

**Records:** 30 employees
**Departments:** 13
**Locations:** 4

## 🛠️ SQL Concepts Practiced

* `SELECT`
* `DISTINCT`
* Column aliases using `AS`
* `WHERE` clause
* Comparison operators
* `ORDER BY`
* `LIMIT`
* Aggregate functions

  * `SUM()`
  * `MIN()`
  * `MAX()`
  * `AVG()`
  * `COUNT()`
* `GROUP BY`
* `HAVING`
* Filtering using `LIKE`
* Working with `NULL` values
* Basic data analysis using SQL

## 🔍 Queries Practiced

Some of the questions explored in this project include:

* Finding distinct salary values
* Creating aliases for employee age and salary
* Finding employees earning more than ₹50,000
* Filtering employees based on their hire date
* Identifying missing designations
* Sorting employees by department and salary
* Finding the first five employees hired in 2018
* Calculating total salary in the Finance department
* Finding the minimum employee age
* Finding the maximum salary by location
* Calculating average salary for Analyst roles
* Finding departments with fewer than three employees
